        Guida rapida
        
  
          
    
        1. Registra con il pulsante rosso in basso, oppure importa un file nella scheda 1. Prima di registrare usa “Prova il livello”: le parole forti devono stare tra -12 e -6 dB, senza la scritta rossa di saturazione.
          2. 
    
        2. Monta. Trascina sulla forma d’onda per selezionare. Poi taglia, copia, incolla, elimina o metti silenzio. Sui tagli il programma aggiunge da solo una dissolvenza brevissima, così non si sentono clic. Tutto si può annullare.
          3. 
    
        3. Migliora nella scheda 2: scegli uno stile e premi “Applica i miglioramenti”. Confronta Originale e Migliorata in basso, con “Stesso volume” attivo, o alla cieca.
          4. 
    
        4. Aggiungi musica ed effetti nella scheda 3, se servono. La musica scende da sola quando parli.
          5. 
    
        5. Esporta nella scheda 4: WAV a 24 bit per lavorare ancora, MP3 con titolo, autore e copertina per pubblicare.
          6.

            Benvenuto in Sottovoce Officina Sonora
            
  
            Dalla voce registrata al file pronto da pubblicare, in cinque passi.
            
  
              
    
            1. Carica o registra la voce: trascina un file audio nella pagina, oppure premi Registra.
              2. 
    
            2. Ascolta con il pulsante Riproduci in basso, o con la barra spaziatrice.
              3. 
    
            3. Nella scheda Migliora premi Modalità Podcast: il programma sistema la voce da solo. Se preferisci scegliere tu, c’è Analizza e proponi.
              4. 
    
            4. Ascolta il risultato e confronta Originale e Migliorata in basso.
              5. 
    
            5. Nella scheda Esporta premi Esporta: MP3 per pubblicare, WAV per continuare a lavorare.
              6.
