# Esportare

Scheda **4. Esporta**. Il file finale suona come l'ascolto, al volume giusto.

## MP3 o WAV

| Formato | Quando usarlo |
|---|---|
| **MP3** | Per pubblicare. File leggero, con titolo, autore e copertina |
| **WAV** | Per continuare a lavorare in altri programmi, senza perdita di qualità |

## Le opzioni

- **Qualità dell'MP3**: per il parlato bastano 128 kbps; 192 kbps (predefinito) è un buon compromesso con la musica; 320 è la più alta.
- **Profondità del WAV**: 24 bit (predefinito) se il file andrà ancora lavorato; 16 bit pesa meno.
- **Frequenza di campionamento**: 48 kHz (predefinito) è il formato di lavoro dell'app; 44,1 kHz solo se una piattaforma lo chiede.
- **Canali**: in automatico mono se c'è solo la voce, stereo se ci sono musica o effetti.
- **Voce da usare**: migliorata oppure originale.
- **Porta il file al volume finale** e **Volume finale**: **-16 LUFS** è il riferimento per i podcast; -19 lascia più margine se il file andrà ancora mixato.
- **Tetto dei picchi (true peak)**: **-1 dBTP** evita distorsioni quando le piattaforme convertono il file.
- **Solo la selezione**: esporta solo il tratto selezionato, per esempio un capitolo alla volta.

## Titolo, autore e copertina

Le app dei podcast e i lettori musicali li mostrano. Puoi indicare:

- **Titolo** (diventa anche il nome del file), **Autore**, **Podcast, serie o libro**, **Anno**, **Numero dell'episodio** (per esempio `3` oppure `3/12`), **Descrizione**;
- la **copertina**: meglio un'immagine quadrata, viene ridotta a 1400 × 1400 pixel.

## Tracce separate

**Tracce separate** crea un WAV per ogni traccia (voce, musica, effetti), tutti della stessa durata. Servono se vuoi rifare il mix in un altro programma. Il browser permette un solo download per clic: scaricali uno alla volta oppure tutti insieme con **Scarica tutto in uno zip**.

## Ultima esportazione

Dopo l'esportazione, Sottovoce misura il file appena creato (volume in LUFS e picco) così sai subito se è pronto per la pubblicazione.
