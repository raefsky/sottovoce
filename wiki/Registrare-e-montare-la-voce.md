# Registrare e montare la voce

Scheda **1. Voce**.

## Registrare

1. Scegli il microfono nell'elenco **Microfono** (i nomi compaiono dopo il primo permesso del browser).
2. Premi **Prova il livello** e parla come farai nella registrazione: le parole forti devono stare **tra -12 e -6 dB**, senza la scritta rossa di saturazione.
3. Premi **Registra** (o `R`) e di nuovo per fermare.

L'app registra la voce così com'è, in alta qualità, a 48 kHz. I miglioramenti si applicano dopo e si possono sempre togliere.

### Dove finisce la nuova registrazione

L'opzione **Dove va la registrazione** decide dove va una nuova registrazione o un file importato:

- **In fondo**: dopo tutto il resto.
- **Al cursore**: nel punto del cursore; il resto si sposta in avanti.
- **Al posto della selezione**: sostituisce il tratto selezionato, utile per rifare una frase.
- **Al posto di tutta la voce**: musica, effetti e titolo restano.

## Importare un file

Usa **Importa un file** o trascina il file nella pagina. Formati accettati: **WAV, MP3, M4A, FLAC**.

Per una nuova versione completa della voce c'è **Sostituisci tutta la voce**: musica, effetti, titolo e regolazioni restano. Se cambi idea, basta **Annulla**.

## Montare

Trascina sulla forma d'onda per selezionare un tratto, poi:

| Comando | Cosa fa |
|---|---|
| **Taglia / Copia / Incolla** | Come in un editor di testo |
| **Elimina** | Toglie il tratto selezionato |
| **Crea silenzio** | Sostituisce il tratto con silenzio |
| **Correggi selezione** | Ritocca solo quel tratto: **Riduci respiro** abbassa un respiro o un rumore, **Ripara click** toglie gli schiocchi di bocca |
| **Ascolta selezione** | Riascolti solo il tratto selezionato |
| **Dissolvenza** | Entrata o uscita graduale |

Su ogni taglio l'app aggiunge da sola una dissolvenza incrociata brevissima (**Dissolvenza sui tagli**, 10 ms), così non si sentono clic.

**Tutto si può annullare, senza limiti.** L'originale resta intatto: la **Cronologia** mostra ogni modifica in ordine.

## Accorciare le pause lunghe

In **Silenzi lunghi** premi **Cerca le pause** e poi **Accorcia le pause**. Puoi scegliere:

- **Pausa minima da accorciare**: le pause più brevi restano come sono;
- **Durata da lasciare**: quanto resta di ogni pausa (0,6 s è un respiro naturale tra due frasi).

## Vedere meglio

- **Altezza della forma d'onda**: automatica oppure ×1, ×2, ×4, ×8, ×16, utile per le parti dette piano.
- **Frequenze**: spente, spettro medio o spettrogramma.
- **Zoom**: `Ctrl`/`⌘` + rotellina, o pizzico sul trackpad.

## Tastiera e mouse

| Tasto | Azione |
|---|---|
| `Spazio` | Riproduci o pausa (con una selezione ascolti solo quella) |
| `R` | Registra o ferma |
| `Ctrl+Z` / `⌘Z` | Annulla |
| `Ctrl+Y` / `⇧⌘Z` | Ripeti |
| `Ctrl`/`⌘` + `X` `C` `V` | Taglia, copia, incolla |
| `Backspace` / `⌫` | Elimina la selezione |
| `Ctrl`/`⌘` + `L` | Silenzio al posto della selezione |
| `Ctrl`/`⌘` + `A` | Seleziona tutto |
| `Esc` | Togli la selezione |
| `←` `→` | Sposta il cursore di un secondo (con `⇧` allarga la selezione) |
| `Home` / `Fine` | Vai all'inizio o alla fine |
| Doppio clic | Seleziona il pezzo tra due tagli |
| Trascinare la riga dei tempi | Sposta il cursore senza selezionare |
